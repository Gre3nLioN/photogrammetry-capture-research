# Academic paper track

Working title: **Minimum Viable Capture Budgets for Low-Cost Photogrammetry: A Controlled Study of Coverage, Image Count, and Image Quality**

## Planned sections

1. Abstract
2. Introduction and practical motivation
3. Related work
4. Datasets and reference reconstructions
5. Experimental methodology and immutability contract
6. Coverage, frame-rate, and image-budget results
7. Failure analysis using ReconCheck diagnostics
8. Threats to validity and generalization limits
9. Practical implications
10. Conclusion

## Publication discipline

- Every result table links to immutable experiment IDs and report hashes.
- Claims distinguish internal consistency from ground-truth accuracy.
- Scene-specific results are never presented as universal capture thresholds.
- The practical guide may summarize only completed, reproducible conditions.
